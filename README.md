# Engineering College — React Week 5 Practice

This is a complete Vite + React source project based on the provided screenshots (sections 5.1–5.6).

## Run in WebStorm / Windows

1. Install Node.js (includes npm).
2. Extract the ZIP and open the `react_student_lab` folder in WebStorm (File → Open).
3. Open Terminal (Alt + F12).
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (normally http://localhost:5173/).
6. To check the production build, run `npm run build`.

## Assignment coverage

- **5.1 Project setup:** Vite + React, App.jsx, main.jsx, components and props.
- **5.2 Deployment:** Ready for GitHub and Vercel. Actual deployment must be performed in your own accounts; no live URL is included.
- **5.3 Hello React:** custom App, heading, React description, dynamic year in footer.
- **5.4 JSX & components:** Title, Subtitle, Paragraph, HighlightBox; StudentCard receives name, group and favoriteSubject as props.
- **5.5 State:** Counter (+/−), CourseInfo show/hide details, controlled input.
- **5.6 Mini project:** hard-coded students with name/track/isActive; StudentList uses `.map()` and stable keys; StudentFilter uses state for All/Active only; active students styled differently.

## Deploy with Vercel

1. Push this folder to a new GitHub repository.
2. Sign into Vercel with GitHub and import the repository.
3. Choose **Vite** as framework preset, **npm run build** as build command and **dist** as output directory.
4. Click **Deploy** and save the resulting URL for your teacher.

## Important

The `node_modules` and `dist` folders are not included in the ZIP; they are generated by `npm install` and `npm run build` respectively. Student records are sample data, not real student information.
